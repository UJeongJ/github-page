# 산업연관 연구실

한국은행 **2023년 연장 투입산출표(2023년 생산자가격)**로 산업 간 거래를 검색하고, 국산 상품에 대한 최종수요가 바뀔 때의 파급효과를 계산하는 웹앱입니다. 공식 표는 통합대분류 33개, 통합중분류 83개, 통합소분류 165개, 기본부문 380개이며, 각 분류의 12개 시트를 이용합니다.

## 사용법

1. **투입산출표 불러오기**에서 분류를 선택하고 **공식 자료 불러오기**를 누릅니다. 내 파일을 쓰려면 **내 엑셀 열기**에서 같은 형식의 원본 `.xlsx`를 선택합니다. 원본의 연도·가격·시트·코드·금액 단위로 구성을 검증하고 분류를 자동 판별합니다. 파일은 브라우저에서만 읽고 외부로 전송하거나 저장하지 않습니다.
2. **시트 탐색**에서 시트명을 검색·선택합니다. **행 검색**과 **열 검색**에 각각 코드나 이름을 입력하면 교차값을 볼 수 있습니다. 여러 결과는 행·열의 이전/다음 버튼으로 봅니다. `—`는 빈 값이고 `0`은 수치 0입니다.
3. **산업연관 분석 → 수요 변화 시나리오**에서 산업과 변화액을 입력하고 **파급효과 계산**을 누릅니다. 최대 8개 항목을 동시에 적용할 수 있고, 같은 부문의 변화액은 합산됩니다. 수요가 줄면 음수를 넣습니다. 결과 합계와 부문별 금액을 생산·부가가치·수입 중 원하는 기준의 절댓값 순으로 봅니다.
4. **산업 구조와 수요 실적**에서 산업을 골라 총산출, 투입률·부가가치율, 영향력·감응도 계수와 주요 국산 중간재 공급 부문을 봅니다. 최종수요 항목을 바꾸면 그 항목으로부터 선택 부문에 실제 유발된 생산·수입·부가가치 금액을 확인할 수 있습니다.

## 분석 방법

### 표의 방향과 표시 단위

- 거래표 및 투입계수표에서 **행**은 투입되는 상품, **열**은 그 상품을 사용하는 생산 부문입니다(오른쪽에는 소비·투자·수출·공급 등 별도 항목이 들어갈 수 있습니다). 유발계수표에서 행은 효과가 나타나는 부문, 열은 최종수요가 바뀐 부문입니다. 최종수요 항목별 유발액에서는 열이 민간·정부 소비, 민간·정부 고정자본형성, 재고, 귀중품, 수출 등 수요 항목입니다.
- 거래액·유발액과 시나리오 입력/결과는 **백만원**, 2023년 **당해년 생산자가격**입니다. `1,000백만원 = 10억원`. 물가 조정 실질액이 아닙니다. 화면에서 금액과 %는 소수점 이하 최대 3자리, 계수는 유효숫자 최대 7자리로 표시하며, 계산은 표시 전 정밀도를 사용합니다.
- 투입계수와 유발계수는 **무차원**입니다. 투입계수는 산출 1원당 투입액(원/원), 유발계수는 해당 최종수요 1원당 유발액(원/원)입니다. 영향력·감응도는 전체 부문 평균이 1인 무차원 지수입니다. 기준표 `구성비(%)`만 **%**이고, 같은 시트의 `유발계수` 요약 행은 무차원입니다. 분석의 중간투입률, 수입 중간투입률, 부가가치율은 해당 투입계수에 100을 곱해 **%**로 표시합니다.

### 최종수요 시나리오

`Δfᵈ`는 **국산 상품에 대한 최종수요** 변화를 상품별 백만원으로 나타낸 열벡터입니다. 수입 완제품을 직접 사는 금액은 포함하지 않습니다. 한국은행 공표 유발계수에서 산업 코드 순서를 검증하고, 합계·지수 행과 열을 제외한 산업×산업 구간만 곱합니다.

| 지표 | 계산 |
|---|---|
| 생산 | `Δx = L × Δfᵈ`, `L = (I − Aᵈ)⁻¹` (공표 생산유발계수) |
| 수입 | `Δm = (Aᵐ × L) × Δfᵈ` (공표 수입유발계수; 생산에 수반되는 중간재 수입) |
| 부가가치 | `Δv = (diag(v) × L) × Δfᵈ` (공표 부가가치유발계수) |

`Aᵈ`는 국산투입계수, `Aᵐ`는 수입투입계수, `v`는 부문별 부가가치율(백분율이 아닌 비율)입니다. 합계는 부문별 결과의 부호를 유지해 더합니다. 예를 들어 통합대분류에서 `A 농림수산품`의 국산 최종수요가 `1,000백만원` 늘면 생산 약 `1,964.069백만원`, 부가가치 `815.630백만원`, 수입 `184.370백만원`이 유발됩니다.

### 산업 구조와 해석

- 중간투입률은 총 중간투입/총투입, 수입 중간투입률은 수입 중간투입/총투입, 부가가치율은 부가가치/총투입입니다. 주요 공급 부문은 선택 열의 국산투입계수 중 양수 상위 8개입니다. 자료의 음수·빈값은 탐색 표에서 그대로 구분합니다.
- 영향력계수는 해당 열합을 전체 평균 열합으로 나눈 값입니다(후방연쇄). 감응도계수는 해당 행합을 전체 평균 행합으로 나눈 값입니다(전방연쇄). 1보다 크면 해당 분류 수준 평균보다 높습니다. 서로 다른 분류의 지수는 평균 기준이 달라 직접 비교하지 않습니다.
- 공표된 **수요 실적**은 원본 시트의 2023년 항목별 결과이고, **시나리오**는 국산 수요의 가상 변화입니다. 집계 수준별 산업 구조가 다르고 원자료에 반올림이 있으므로 값이 다른 분류의 단순 합과 일치하지 않을 수 있습니다. 시나리오는 고정된 투입구조·가격의 선형 모형이며 공급제약, 가격 변화, 행동 변화는 반영하지 않습니다. 예측값이나 인과효과가 아닙니다.

## GitHub Pages 게시

1. 이 프로젝트를 GitHub 저장소의 `main`에 올립니다. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 지정합니다.
2. **Actions → GitHub Pages → Run workflow**를 실행합니다(이후 `main` 변경 시 자동 실행). 게시가 성공하면 실행 내 `github-pages` 환경 또는 **Settings → Pages**의 공개 주소를 엽니다. 보통 프로젝트 저장소는 `https://<계정>.github.io/<저장소>/`, 계정 사이트는 `https://<계정>.github.io/`입니다.
3. 공개 주소에서 네 분류 각각의 불러오기, 행·열 검색, 시나리오 계산을 확인합니다. 저장소의 하위 주소에서도 자료와 자산을 읽도록 Pages가 제공하는 기준 주소를 사용합니다. 비공개 저장소는 계정 요금제 또는 조직 설정에 따라 Pages를 쓸 수 없거나 사이트 공개 범위가 별도로 적용될 수 있습니다.

로컬 확인: Node.js 24에서 `npm ci`, `npm run dev`. 계산 회귀 검사: `npm run test:io`. 정적 파일 생성: `npm run build` (`dist/`). 공개 앱은 별도의 서버나 키를 요구하지 않습니다.
